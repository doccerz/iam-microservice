     Step 3 — Docker build & start

     (DB + seed are run by the app container entrypoint on startup.)

     Step 4 — Docker E2E verification

     4a. Register + login as a regular user (get IDs)

     # Register
     curl -s -X POST http://localhost:3000/auth/register \
       -H "Content-Type: application/json" \
       -d '{"email":"testuser@example.com","password":"password123"}' | jq

     # Login (save accessToken)
     curl -s -X POST http://localhost:3000/auth/login \
       -H "Content-Type: application/json" \
       -d '{"email":"testuser@example.com","password":"password123"}' | jq

     4b. Grant admin role directly in DB (user needs role:write)

     docker compose exec db psql -U postgres -d postgres -c \
       "INSERT INTO \"user-service\".user_roles (user_id, role_id)
        SELECT u.id, r.id
        FROM \"user-service\".users u, \"user-service\".roles r
        WHERE u.email = 'testuser@example.com' AND r.slug = 'admin';"

     4c. Re-login to get token with role:write in JWT

     curl -s -X POST http://localhost:3000/auth/login \
       -H "Content-Type: application/json" \
       -d '{"email":"testuser@example.com","password":"password123"}' | jq

     4d. Get the admin role ID from DB

     docker compose exec db psql -U postgres -d postgres -c \
       "SELECT id, slug FROM \"user-service\".roles;"

     4e. Register a target user to modify roles for

     curl -s -X POST http://localhost:3000/auth/register \
       -H "Content-Type: application/json" \
       -d '{"email":"target@example.com","password":"password123"}' | jq
     # note the returned id

     4f. Call PUT /users/:id/roles

     curl -s -X PUT http://localhost:3000/users/<TARGET_USER_ID>/roles \
       -H "Content-Type: application/json" \
       -H "Authorization: Bearer <ACCESS_TOKEN>" \
       -d '{"roleIds":["<ADMIN_ROLE_UUID>"]}' | jq

     Expected response: { "success": true } with HTTP 200.

     4g. Verify edge cases

     # 404 — non-existent user
     curl -s -X PUT
     http://localhost:3000/users/00000000-0000-0000-0000-000000000000/roles \
       -H "Authorization: Bearer <ACCESS_TOKEN>" \
       -H "Content-Type: application/json" \
       -d '{"roleIds":["<ADMIN_ROLE_UUID>"]}' | jq
     # Expected: { "success": false, "error": "User not found" } — 404

     # 400 — missing roleIds
     curl -s -X PUT http://localhost:3000/users/<TARGET_USER_ID>/roles \
       -H "Authorization: Bearer <ACCESS_TOKEN>" \
       -H "Content-Type: application/json" \
       -d '{}' | jq
     # Expected: 400

     # 401 — no token
     curl -s -X PUT http://localhost:3000/users/<TARGET_USER_ID>/roles \
       -H "Content-Type: application/json" \
       -d '{"roleIds":["<ADMIN_ROLE_UUID>"]}' | jq
     # Expected: 401
