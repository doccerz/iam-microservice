     Step 1: Write Failing Tests (src/db/__tests__/seed.test.ts)

     Follow the existing test pattern from src/db/__tests__/migrate.test.ts:
     - Mock ../index.js (db, sql), ../../config/env.js
     - Mock drizzle's insert().values().onConflictDoNothing() chain
     - Use dynamic await import("../seed.js") pattern

     Test cases:
     1. seedDatabase() inserts 5 permissions with onConflictDoNothing()
       - Permissions: user:read, user:write, user:delete, role:read, role:write
     2. seedDatabase() inserts 2 roles with onConflictDoNothing()
       - Roles: admin (name: "Admin"), user (name: "User")
     3. seedDatabase() inserts role-permission mappings with
     onConflictDoNothing()
       - Admin gets all 5 permissions, User gets only user:read
     4. seedDatabase() calls operations in correct order (permissions first,
     then roles, then role_permissions)
     5. Error propagation — if any insert fails, the error propagates

     Mocking approach for insert chain:
     const mockOnConflictDoNothing = vi.fn().mockResolvedValue(undefined);
     const mockValues = vi.fn(() => ({ onConflictDoNothing:
     mockOnConflictDoNothing }));
     const mockInsert = vi.fn(() => ({ values: mockValues }));
     const mockDb = { insert: mockInsert, $client: mockSqlClient };

     For returning inserted rows (needed for role_permissions linking), use
     .returning():
     // permissions insert returns [{id, slug}, ...]
     // roles insert returns [{id, slug}, ...]

     Step 2: Implement Seed Script (src/db/seed.ts)

     Follow the pattern from src/db/migrate.ts for the entry-point script
     structure.

     export async function seedDatabase(): Promise<void> {
       // 1. Insert permissions with onConflictDoNothing(), use .returning() to 
     get IDs
       // 2. Insert roles with onConflictDoNothing(), use .returning() to get 
     IDs
       // 3. Query back permissions and roles by slug (since onConflictDoNothing
      returns empty on conflict)
       // 4. Build role_permissions mapping:
       //    - admin: all permission IDs
       //    - user: only user:read permission ID
       // 5. Insert role_permissions with onConflictDoNothing()
     }

     Key implementation detail: Since onConflictDoNothing() returns empty arrays
      when rows already exist, we need to query back the permissions and roles
     by slug after inserting to reliably get their IDs for the role_permissions
     join table.

     Tables/imports needed:
     - roles, permissions, rolePermissions from ./schema/index.js
     - db, sql from ./index.js
     - eq, inArray from drizzle-orm (for querying back)

     Entry point pattern (matching migrate.ts):
     if (require.main === module) {
       seedDatabase()
         .then(() => sql.end())
         .catch((err) => {
           console.error("Seed failed:", err);
           process.exit(1);
         });
     }
