     Context

     Setting up a greenfield IAM microservice from scratch. The project
     directory currently has only CLAUDE.md, README.md, AGENTS.md, and specs/.
     We need to initialize the Node.js project, install dependencies, and create
      all config files.

     Steps

     1. Initialize npm and install dependencies

     npm init -y
     npm install express drizzle-orm postgres argon2 jsonwebtoken zod dotenv
     npm install -D typescript @types/express @types/jsonwebtoken @types/node
     tsx drizzle-kit

     2. Update package.json scripts

     {
       "dev": "tsx watch src/server.ts",
       "build": "tsc",
       "start": "node dist/server.js",
       "db:generate": "drizzle-kit generate",
       "db:migrate": "tsx src/db/migrate.ts",
       "db:seed": "tsx src/db/seed.ts"
     }

     3. Create tsconfig.json

     - target: ES2022, module: NodeNext, moduleResolution: NodeNext
     - strict: true, outDir: ./dist, rootDir: ./src
     - esModuleInterop: true, skipLibCheck: true

     4. Create drizzle.config.ts

     - schema: src/db/schema/index.ts
     - out: ./drizzle
     - dialect: postgresql, connection from DATABASE_URL env var

     5. Create .env.example

     DATABASE_URL=postgresql://user:password@localhost:5432/iam_db
     JWT_ACCESS_SECRET=your-access-secret
     JWT_REFRESH_SECRET=your-refresh-secret
     JWT_ACCESS_EXPIRY=15m
     JWT_REFRESH_EXPIRY=7d
     PORT=3000
     DEFAULT_ROLE_SLUG=user

     6. Create .gitignore

     Standard Node.js gitignore: node_modules/, dist/, .env, drizzle/

     7. Create .dockerignore

     node_modules/, dist/, .env, .git/

     8. Create src/config/env.ts

     - Load dotenv
     - Export typed config object with all env vars
     - Defaults: PORT=3000, JWT_ACCESS_EXPIRY="15m", JWT_REFRESH_EXPIRY="7d",
     DEFAULT_ROLE_SLUG="user"
     - Throw on missing required vars: DATABASE_URL, JWT_ACCESS_SECRET,
     JWT_REFRESH_SECRET

     Files to create

     - package.json (via npm init + install)
     - tsconfig.json
     - drizzle.config.ts
     - .env.example
     - .gitignore
     - .dockerignore
     - src/config/env.ts

     Verification

     - npx tsc --noEmit should pass with no errors (after creating a minimal src
      structure)
     - Confirm all config files exist and are well-formed
